[[introduction]]
== Introduction

Spexarkivet Server is the backend of Spexarkivet, FGV's archive of the spex' manuscripts and musical arrangements.

The purpose of this documentation is to provide details on how to develop within Spexarkivet Server and how to integrate Spexarkivet Server into another application, e.g. a web application.
