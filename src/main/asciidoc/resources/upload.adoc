Files are uploaded with https://tus.io/protocols/resumable-upload[tus 1.0.0], with the extensions `creation` and
`termination`, so a large file survives a broken connection.
The upload's id is then given to the GraphQL mutation that makes it a file of a version (`fileAdd`) or replaces a file's content (`fileReplace`), which checks its type by content.
An upload that is not used is deleted after 24 hours.
Only its owner can reach an upload, and the largest is the admins' setting (`Settings.maxUploadMb`).

Send chunks of at most 50 MB: Cloudflare, in front of the staging server, refuses larger requests.
